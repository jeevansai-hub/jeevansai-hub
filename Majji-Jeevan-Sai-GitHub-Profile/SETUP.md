# Installation

1. Create a repository with the exact same name as your GitHub username:
   `jeevansai-hub`
2. Upload these three files to the repository root:
   - `README.md`
   - `dark.svg`
   - `light.svg`
3. Commit and push the files.
4. Open your GitHub profile. GitHub will automatically display the README.

## Notes

- The banner uses pure SVG and SMIL animations; no JavaScript or `foreignObject`.
- The `<picture>` element automatically switches between `dark.svg` and `light.svg`.
- Some GitHub clients may reduce or pause animation based on accessibility or browser settings.
